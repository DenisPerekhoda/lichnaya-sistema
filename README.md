# Личная система

Личный сайт-кабинет: проекты как бизнес-юниты, структура дохода, общая воронка сделок, задачи на сегодня, цели цикла с ключевыми результатами, еженедельный чек-ин и публичная витрина для клиентов.

Стек: React + Vite, база и вход — Supabase, хостинг — GitHub Pages. Всё на бесплатных тарифах.

## Запуск за 20 минут

### 1. Supabase — база и вход
1. Зарегистрируйся на [supabase.com](https://supabase.com) и нажми **New project** (тариф Free, регион — ближайший, например Frankfurt).
2. Открой **SQL Editor → New query**, вставь целиком файл `supabase/schema.sql` и нажми **Run**.
3. **Project Settings → API**: скопируй `Project URL` и ключ `anon public`. Ключ `anon` можно хранить открыто: доступ к данным защищён правилами RLS.

### 2. GitHub — код и сайт
1. Создай репозиторий типа **Public**: на бесплатном тарифе GitHub Pages работает только с публичными репозиториями. Открытым будет только код. Твои данные хранятся в Supabase и закрыты входом.
2. Загрузи туда файлы проекта.
3. **Settings → Secrets and variables → Actions → вкладка Variables** → добавь:
   - `VITE_SUPABASE_URL` — Project URL
   - `VITE_SUPABASE_ANON_KEY` — anon public key
4. **Settings → Pages → Source: GitHub Actions**.
5. **Actions → Deploy to GitHub Pages → Run workflow** (или просто сделай любой коммит в `main`). Через 1–2 минуты сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

### 3. Первый вход
Вход по почте и паролю, письма не нужны (в Supabase выключено **Confirm email**).
1. Открой сайт → «Первый раз? Создать аккаунт» → почта и пароль.
2. Раздел **«Витрина и данные» → «Заполнить»** — подтянутся проекты, сделки, цели и витрина.
3. Supabase → **Authentication → Sign In / Providers** → выключи **Allow new users to sign up**, чтобы никто другой не завёл аккаунт.

## Разделы
- **Кабинет** — 4 цели наверху, структура дохода, бизнес-юниты (правятся прямо в таблице), воронка сделок по этапам.
- **Сегодня** — главное действие дня, задачи: просроченные, на сегодня, без срока, дальше.
- **Цели и чек-ин** — видение, цели цикла с ключевыми результатами, еженедельный чек-ин с историей.
- **Витрина и данные** — публичная страница для клиентов (`/#/showcase`), цифры целей, стартовые данные.
