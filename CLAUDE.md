Личный сайт-кабинет Дениса Перехода: финансы относительно целей, проекты (бизнес-юниты), задачи на сегодня, цели цикла с чек-ином, публичная витрина.
Сайт: https://denisperekhoda.github.io/lichnaya-sistema/

## Как общаться

- Пользователь не программист. Отвечай по-русски, простыми словами, без жаргона. Говори, что изменилось на сайте и что ему сделать, а не какие файлы ты трогал.
- Перед крупной переделкой (новый раздел, смена структуры) коротко опиши план и дождись согласия. Мелкие правки делай сразу.

## Стек и выкладка

- React 18 + Vite 5, `react-router-dom` с `HashRouter` (адреса вида `/#/today`), `@supabase/supabase-js`.
- Хостинг GitHub Pages. Пуш в `main` → GitHub Actions `.github/workflows/deploy.yml` → сайт обновляется сам.
- Адрес и публичный ключ Supabase лежат в `.env.production` (это публичный ключ, так и задумано; доступ к данным закрывает RLS).
- Локально: `npm install`, `npm run dev`. Для `dev` нужен `.env` с теми же переменными (см. `.env.example`).
- Коммиты подписывай `Denis Perekhoda <DenisPerekhoda@users.noreply.github.com>`. Личную почту пользователя в коммиты и код не вставляй.

## Supabase

- Проект `lichnaya-sistema`, id `jkatklipqmnfjdienafw`, регион eu-central-1. Отдельный от старого проекта `12_week_app`, его не трогай.
- Таблицы: `settings`, `projects`, `deals`, `tasks`, `goals`, `key_results`, `checkins`, `profile`, `showcase_cases`, `fin_snapshots`, `invest_raw`. У всех включён RLS «только владелец». Витрина (`profile`, `showcase_cases`) читается всеми, если `is_public`.
- Вход: почта и пароль. Подтверждение почты выключено (бесплатная почта Supabase шлёт ~2 письма в час). Регистрация новых пользователей **выключена**: пользователь один.
- Схему меняй миграциями и после изменений проверяй советы безопасности Supabase.

## Финансы: откуда данные

- **Т-Инвестиции:** функция `tinvest-sync` (секрет `TINVEST_TOKEN`, токен только для чтения) каждый день в 06:45 МСК (pg_cron `tinvest-sync-daily`) пишет портфель в `invest_raw`. API Т-Инвестиций подписан сертификатом Минцифры: функция скачивает корневой и выпускающие сертификаты с gu-st.ru и создаёт свой HTTP-клиент. Если синхронизация падает с ошибкой сертификата, первым делом проверь эти адреса.
- **Zenmoney + выводы:** ежедневная задача Claude в 07:10 МСК («Личная система · обновление раздела «Финансы»») берёт `get_monthly_report` за 12 месяцев и `list_accounts`, забирает портфель через `rpc/fin_export_invest`, пишет выводы (`narrative`), собирает снимок `scripts/build_snapshot.py` и сохраняет через `rpc/fin_ingest_snapshot`. Ключ этих функций хранится в `private.config` и в тексте задачи, **никогда не клади его в репозиторий**.
- Сайт показывает последний снимок из `fin_snapshots`. Если меняешь структуру снимка, поменяй и `build_snapshot.py`, и `Finance.jsx`, и сохраняй совместимость со старыми снимками (поля могут отсутствовать).
- Настройки в начале `build_snapshot.py`: группы счетов (инвестиции, долгосрочные, подушка, счета ИП), разовые доходы вне базы, цель дохода 1 млн, цель +50 тыс. в месяц, ключевая ставка.
- Цели пользователя: доход 1 000 000 ₽ в месяц; оставлять не меньше +50 тыс. ₽ каждый месяц; лимит расходов = база доходов − 50 тыс.
- Известные ограничения: купоны за прошлые месяцы не показываем (брокер даёт только текущее количество бумаг); купон амортизируемых выпусков не считаем; бумаги с нулевой ценой (дефолт) исключены из сумм и перечислены отдельно.
- В Zenmoney только читай, ничего не меняй. Не давай советов купить или продать конкретные бумаги.

## Дизайн

Редизайн сделан по системе Hallmark (штамп в начале `src/styles.css`). Тёмная тема, стиль как у renta.life: глубокий сине-серый фон, приподнятые карточки со скруглением 16px, переключатели-«таблетки», один зелёный акцент. Шрифт **IBM Plex Sans** (подключён в `index.html`).

Правила, которые нельзя нарушать:
- Все цвета и шрифты только через переменные из `src/tokens.css`. Никаких цветов прямо в CSS или JSX, кроме `var(--…)`.
- Анимировать только `transform` и `opacity`; никогда `transition: all`, ширину или высоту. Прогресс-полосы через `scaleX`.
- В текстах интерфейса нет длинного тире (—): вместо него запятая, двоеточие или точка. Прочерк «—» допустим только как значение пустой ячейки.
- Нет подписей капслоком и с разрядкой, нет «надзаголовков» над заголовками.
- Не выдумывать цифры, отзывы, логотипы: только данные пользователя.
- Карточка не кладётся в карточку. Таблицы без внешней рамки, только горизонтальные линии.
- У всего интерактивного виден фокус; кнопки — настоящие `<button>`, ссылки — `<a>`.
- Страницы работают на телефоне (390px): проверяй узкий экран.
- Перед выкладкой прогоняй линтер Hallmark, если он доступен: `node <hallmark>/scripts/sloplint.mjs src/styles.css src/App.jsx src/pages src/ui.jsx --genre modern-minimal --scope app`.
